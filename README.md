# RAILSETU
Railway Management System
A web-based CRUD (Create, Read, Update, Delete) application designed to manage railway operations, including train schedules, passenger registrations, and ticket bookings. Built with Java Servlets, JSP, JDBC, and MySQL.

🚀 Features
Train Management: Admin can add new trains, update existing train details (source, destination, fare), and view a list of all available trains.

Passenger Registration: Users can register passengers by providing their name, age, and gender.

Ticket Booking System: Dynamic booking interface allowing users to select registered passengers and available trains to confirm a booking.

Booking Management: View a comprehensive list of all active bookings (displaying passenger details alongside train and fare information) and cancel specific bookings.

🛠️ Tech Stack
Backend: Java 17+, Jakarta EE (Servlets & JSP)

Frontend: HTML, CSS, JSP (JavaServer Pages), JSTL

Database: MySQL

Build Tool: Maven

Server: Apache Tomcat (v10.1+)

📋 Prerequisites
To run this project locally, you will need:

Java Development Kit (JDK) 17 or higher

Apache Tomcat 10.1 or higher (Must support jakarta.* namespace)

MySQL Server

Maven installed and added to your system PATH
